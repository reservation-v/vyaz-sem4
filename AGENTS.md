# AGENTS.md

## Проект

Учебный проект по курсу «Веб-технологии» (2 семестр, преподаватель Вяз).

Тема семестра: **сайт + приложение платформы коворкинга** — аренда рабочих мест и переговорок.

Прикладной сервис сайта (приложение к БД, бронирование) разрабатывается с нуля в рамках этого семестра. Связей с прошлым семестром (БД-приложение ресторана) нет — всё делается с нуля.

## Стек

- Go (модуль `coworking`, только `pgx/v5`), серверный рендеринг `html/template`, чистый `net/http`
- PostgreSQL 18 в Docker Compose (наружный порт `49733`), миграции `migrate/migrate` (встроены через `embed`), сиды в миграциях
- Статическая часть сайта: HTML/CSS/JS без фреймворков
- Запуск сайта: `go run ./cmd/server` → http://localhost:8081

## Предметная область

Коворкинг (гибкое офисное пространство):

- локации-офисы, типы пространств (деск-места, переговорки, кабинеты), конкретные места и переговорки
- клиенты (люди и команды), которые бронируют
- брони с почасовым тарифом и периодными тарифами (день/неделя/месяц), статусы (подтверждена/отменена), оплата и депозит за переговорку

Схема БД (Лаба 3, 5 таблиц, 36 атрибутов): `offices`, `space_types`, `spaces`, `clients`, `bookings`.
Лаба 4 добавляет свои таблицы отдельной миграцией: `news` (свои новости) и `news_sources` (подключённые RSS-ленты).

## Задачи

Оцифрованные требования семестра и статусы — в `tasks.md` (соседний файл).
Исходное ТЗ преподавателя: `tasks-2sem.txt`.

## Структура

- Проект автономен: Go-приложение (`cmd/`, `internal/`), шаблоны и статика внутри этого репозитория; БД подключена в Лабе 3 (`db/migrations`, `internal/infrastructure/postgres`)
- Новости (Лаба 4): `internal/application/news_service.go`, `internal/infrastructure/rss`, `internal/infrastructure/postgres/news_repository.go`, страница `internal/interfaces/http/web/templates/news.html`
- Документация: `docs/docs.html` встроена через `docs/embed.go` и отдаётся по `GET /docs`
- `tasks.md` — план работ на семестр (5 лаб), статусы
- `tasks-2sem.txt` — исходное ТЗ
